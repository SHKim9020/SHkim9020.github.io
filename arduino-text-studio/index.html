컴파일과 USB 업로드 도움말

브라우저가 첫 컴파일에 필요한 파일을 내려받습니다. ① 컴파일 후 ③ 보드에 저장·실행을 눌러 포트를 선택하세요. ② USB 연결은 시리얼과 그래프를 볼 때 사용합니다.

인터넷이 연결된 상태에서 오프라인 준비를 한 번 실행하세요. 같은 브라우저에서 오프라인으로 편집·컴파일할 수 있습니다.

라이브러리 버튼으로 추가한 헤더는 브라우저 컴파일러에 포함되어 있습니다. 센서 핀, LCD 주소, LED 개수 같은 설정은 스케치에서 지정하세요.

Android에서는 데이터 USB 케이블과 OTG 어댑터로 UNO R3 또는 CH340 보드를 연결하세요. 그래프 예제는 센서 없이 테스트용 온습도 값을 보냅니다. USB 포트가 보이지 않는 Windows CH340 보드는 공식 드라이버를 확인하세요.
