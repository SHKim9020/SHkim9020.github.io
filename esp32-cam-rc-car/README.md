# OneMaker ESP32-CAM RC Studio

ESP32-CAM(AI Thinker), OV2640, L9110S/MX1508 2채널 모터드라이버를 사용하는 영상탐사 RC카 수업용 블록 코딩 웹앱입니다.

## 기본 배선

| ESP32-CAM | 모터드라이버 | 용도 |
|---|---|---|
| GPIO12 | A-IA / IN1 | 왼쪽 모터 |
| GPIO13 | A-IB / IN2 | 왼쪽 모터 |
| GPIO14 | B-IA / IN3 | 오른쪽 모터 |
| GPIO15 | B-IB / IN4 | 오른쪽 모터 |
| GPIO4 | 내장 Flash LED | 카메라 조명 |
| 5V | VCC(논리/모듈에 맞게) | 전원 |
| GND | GND | 공통 접지 |

> GPIO12·13·14·15는 microSD를 사용하지 않을 때만 모터에 사용할 수 있습니다. GPIO12는 부팅 스트래핑 핀이므로 드라이버가 부팅 중 HIGH로 끌어올리지 않도록 하고, 부팅 문제가 있으면 드라이버 전원을 늦게 연결하거나 입력 풀다운을 확인합니다.

## 수업 흐름

1. 처음에는 `카메라 전용 테스트 펌웨어`를 설치해 OV2640과 Wi-Fi 영상만 확인할 수 있습니다.
2. 테스트 Wi-Fi `OneMaker-CAM-TEST`에 연결한 뒤 `http://192.168.4.1`에서 영상과 카메라 오류 코드를 확인합니다.
3. 영상이 정상이라면 USB-TTL로 RC카 전체 펌웨어를 설치합니다.
4. 블록을 만들고 USB로 RC카에 저장합니다.
5. 스마트폰에서 `OneMaker-RC-01~16` Wi-Fi에 연결합니다. 비밀번호는 `onemaker1`입니다.
6. `http://192.168.4.1`에서 실시간 영상을 보며 조종합니다.

## 포함 기능

- Scratch형 Blockly 편집기: 시작, 계속 반복, Wi-Fi 리모컨·얼굴 감지 이벤트
- 전진·후진·좌회전·우회전, 좌우 모터 개별 속도, 정지
- 카메라 조명, QVGA/VGA/SVGA, 180° 회전
- 변수, 반복, 조건, 계산, 기다리기, 시리얼 출력
- `.omrc` 프로젝트 저장/열기, 교육용 Arduino C++ 보기/다운로드
- Web Serial 프로그램 전송과 ESP Web Tools 펌웨어 설치
- ESP32-CAM 자체 Wi-Fi 실시간 MJPEG 영상 조종기
- 스마트폰 브라우저에서 오프라인으로 실행되는 일반 얼굴 탐지
- `AI 얼굴인식`의 `얼굴이 감지되면`·`얼굴 반대 방향으로 회피` 블록
- 얼굴 3회 연속 탐지 시 정지·후진·반대 방향 회전 후 자동 전진
- AI 모드 중 수동 버튼·AI 정지·화면 이탈 시 즉시 정지
- 버튼 해제·페이지 이탈·900ms 통신 중단 시 모터 자동 정지
- 카메라 XCLK 채널 0과 모터 PWM 채널 4~7을 분리하여 영상 클럭 충돌 방지

## 주의

- ESP32-CAM-MB USB 쉴드를 사용하면 GPIO0-GND 점퍼나 외장 USB-TTL 배선이 필요하지 않습니다.
- MB 쉴드에서 자동 설치가 실패할 때만 IO0/BOOT를 누른 채 RST를 짧게 누른 후 다시 설치합니다.
- 외장 USB-TTL을 사용할 때만 설치 중 GPIO0-GND를 연결하고, 설치 후 분리한 뒤 RST를 누릅니다.
- 모터 전원 노이즈로 재부팅될 수 있으므로 모터 전원과 ESP32-CAM 5V 전원을 안정적으로 설계하고 GND를 공통으로 연결합니다.
- L298N처럼 ENA/ENB가 별도로 필요한 6입력 구성은 기본 핀 수와 맞지 않습니다. L9110S 또는 MX1508형 4입력 드라이버를 권장합니다.
- 얼굴 탐지는 정면 얼굴에 최적화되어 있습니다. 수업 전 밝기와 카메라 각도를 확인하고, 학생 얼굴 사진은 저장하지 않습니다.
