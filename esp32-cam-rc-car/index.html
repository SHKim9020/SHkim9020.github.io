ESP32‑CAM 펌웨어 설치

✅ ESP32-CAM-MB USB 쉴드 사용

  1. ESP32-CAM을 쉴드에 끝까지 꽂고 USB 케이블을 연결합니다.
  2. GPIO 선은 따로 연결하지 않습니다.
  3. 아래 설치 버튼을 누르고 쉴드의 USB 포트를 선택합니다.
  4. 설치 완료 후 RST를 누르거나 USB를 다시 연결합니다.

연결 실패가 나올 때만 IO0/BOOT를 누른 채 RST를 짧게 누르고, IO0/BOOT를 놓은 뒤 다시 설치하세요.

외장 USB-TTL을 사용하는 경우
USB‑TTL TX → U0RUSB‑TTL RX → U0T5V → 5VGND → GND설치할 때만 GPIO0 → GND

① 카메라만 먼저 테스트

모터 기능 없이 OV2640 영상과 Wi‑Fi만 확인합니다. 설치 후 OneMaker-CAM-TEST에 연결하고 192.168.4.1을 여세요.

PC Chrome/Edge에서 설치할 수 있습니다.

② 테스트 후 RC카 전체 기능 설치

카메라와 모터 PWM 충돌을 수정한 RC카 펌웨어 0.1.2입니다. 영상과 조종 버튼을 한 화면에서 사용하며 QVGA가 기본값입니다.

PC Chrome/Edge에서 설치할 수 있습니다.
