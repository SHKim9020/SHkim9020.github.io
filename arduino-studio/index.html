실행 방식

보드에 저장·실행을 누르면 블록 프로그램이 UNO·Nano의 EEPROM에 저장됩니다. 저장 후 USB를 분리해도 보드가 단독으로 실행됩니다.

프로그램 저장 공간은 최대 약 1KB이며, 수업용 중소 규모 블록 프로젝트에 적합합니다.

핀 사용 주의

D0·D1은 USB 시리얼과 겹쳐 기본 목록에서 제외했습니다. UNO·Nano에는 진짜 아날로그 출력(DAC)이 없으므로 PWM 출력 블록을 사용합니다. I²C LCD는 A4(SDA)·A5(SCL)를 사용합니다.

DFPlayer Mini MP3 테스트

DFPlayer TX→Arduino RX, DFPlayer RX←Arduino TX에 연결하세요.

VCC는 5V, GND는 공통으로 연결하고 Arduino TX와 DFPlayer RX 사이에는 1kΩ 직렬 저항을 권장합니다. microSD는 FAT16/32로 포맷하고 0001.mp3 파일을 넣으세요.
