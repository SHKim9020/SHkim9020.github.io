# OneMaker ESP32-C3 Boat Studio

ESP32-C3 Super Mini와 DRV8833, 8520 모터 2개를 사용하는 스마트선박 수업용 블록 코딩 웹앱입니다.

## 웹앱 설치

- Android Chrome에서 페이지를 연 뒤 상단의 `앱 설치`를 누르면 전체화면 독립 앱으로 설치됩니다.
- 설치 버튼이 보이지 않으면 Chrome 메뉴의 `앱 설치` 또는 `홈 화면에 추가`를 선택합니다.
- OneMaker 스마트선박 전용 192px·512px 아이콘과 오프라인 앱 셸 캐시를 포함합니다.
- 텍스트 코드 선택 시 선택한 글자가 사라지지 않으며, 오른쪽 패널 폭은 화면 크기에 맞게 제한되어 블록 코딩 영역을 항상 남깁니다.
- 설치 앱의 창 크기를 바꾸거나 블록 작업공간을 선택해도 상단 펌웨어·USB·저장 메뉴가 사라지지 않도록 데스크톱 스크롤 위치를 자동 복구합니다.

## 기본 배선

| ESP32-C3 | DRV8833 | 용도 |
|---|---|---|
| GPIO1 | IN1 | 왼쪽 모터 |
| GPIO3 | IN2 | 왼쪽 모터 |
| GPIO4 | IN3 | 오른쪽 모터 |
| GPIO5 | IN4 | 오른쪽 모터 |
| 3V3 | VCC | 로직 전원 |
| GND | GND | 공통 접지 |

- OUT1·OUT2: 왼쪽 8520 모터
- OUT3·OUT4: 오른쪽 8520 모터
- 모터 전원은 1S 3.7V 배터리를 DRV8833 모터 전원 입력에 연결
- GPIO2는 스트래핑 핀, GPIO8은 내장 LED이므로 기본 모터 핀에서 제외

## 웹 리모컨

- 보드 탭에서 수업용 선박 번호 `01~16`을 USB로 저장하면 Bluetooth 이름이 `OneMaker Boat 01~16`으로 구분됩니다.
- 번호는 보드의 비휘발성 메모리에 저장되며, 저장 직후 새 이름을 적용하기 위해 보드가 자동으로 재시작됩니다.
- 원격조종 탭의 `연결 끊기` 버튼은 정지 명령을 먼저 보낸 뒤 Bluetooth 연결을 종료합니다.
- `리모컨 버튼을 누르면` 이벤트 블록 아래에 원하는 동작을 연결하고 USB로 한 번 저장합니다.
- 배포 웹앱의 `원격조종` 탭에서 **Bluetooth 보트 연결**을 누르면 Android 또는 PC Chrome/Edge에서 바로 조종할 수 있습니다.
- 원격조종 화면은 좌·우 모터 개별 속도 슬라이더, 선박 방향 표시, 십자형 전진·후진·좌회전·우회전·정지 조정기로 구성됩니다. 직진이 한쪽으로 치우치면 빠른 쪽 모터 값을 조금 낮춰 보정합니다.
- USB로 미리 저장한 시작·반복 프로그램은 Bluetooth 연결 후 `저장된 블록 실행`으로 다시 시작할 수 있습니다. HuskyLens 자율운항을 물 위에서 시작하고 `블록 실행 정지`로 중단하는 용도로 사용할 수 있습니다.
- `전원을 켠 뒤 Bluetooth 시작 버튼까지 대기`를 선택해 저장하면 배터리 전원을 켜도 모터가 자동으로 움직이지 않으며, Bluetooth 실행 버튼을 누를 때 시작합니다. 이 기능은 펌웨어 1.4.5 이상이 필요합니다.
- 속도 슬라이더는 0~250 범위이며 시작값은 150입니다. 고속 시험에서도 소프트 스타트와 연결 끊김 자동정지는 유지됩니다.
- 방향 버튼은 누를 때 한 번만 실행되고 400ms 안전신호만 유지합니다. 신호가 1.1초 동안 끊기면 모터가 자동 정지합니다.
- 출발 시 약 0.25초 소프트 스타트를 적용하고 반대 방향 전환 전에는 180ms 동안 모터를 정지합니다.
- 교실 네트워크와 무관한 예비 방식으로 보드 번호에 따라 `OneMaker-Boat-01~16` Wi‑Fi를 엽니다.
  - 비밀번호: `onemaker1`
  - 조종 주소: `http://192.168.4.1`
- 이벤트 블록이 없는 방향은 기본 전진·후진·좌회전·우회전·정지 동작으로 처리됩니다.

## 내 블록(함수)

- `내 블록` 카테고리에서 반복해서 사용할 동작을 함수로 정의하고 시작·반복·리모컨 이벤트 안에서 호출할 수 있습니다.
- 동작을 묶는 `내 블록`과 숫자·센서 결과를 돌려주는 `값 내 블록`을 지원합니다.
- 함수 정의와 호출 정보는 `.omc3` 프로젝트와 ESP32-C3의 LittleFS 프로그램에 함께 저장됩니다.
- 과도한 재귀 호출로 수업 중 보드가 멈추지 않도록 호출 깊이를 제한합니다.

## 텍스트 코드 보기

- 블록에서 생성된 변수, `setup()`, `loop()`, 내 블록과 리모컨 이벤트만 교육용 C++ 화면에 표시합니다.
- 모터 드라이버와 통신을 위한 내부 구현 함수는 숨기고 Arduino IDE와 비슷한 문법 색상을 적용합니다.
- `계속 반복하기` 앞의 블록은 `setup()`에, 내부 블록은 `loop()`에 생성됩니다.
- 오른쪽 패널의 왼쪽 손잡이를 드래그하거나 방향키로 조절해 코드 영역을 넓힐 수 있습니다.

## HuskyLens 확장

| ESP32-C3 | HuskyLens | 용도 |
|---|---|---|
| GPIO6 | SDA | I²C 데이터 |
| GPIO7 | SCL | I²C 클록 |
| 3V3 | VCC | 전원 |
| GND | GND | 공통 접지 |

- 보드 탭에서 `HuskyLens 블록 사용`을 켜야 센서 연결을 시도합니다.
- 물체 추적·물체 인식·색상 인식·선 추적·얼굴 인식·태그 인식·물체 분류 모드를 제공합니다.
- 학습한 ID가 보이는지 확인하고 X/Y 중심, 너비, 높이를 숫자 블록으로 읽을 수 있습니다.
- GPIO6/7은 기본 모터 핀과 겹치지 않으며 수업 배선에 맞게 변경할 수 있습니다.

## 수업 흐름

1. Chrome 또는 Edge에서 페이지를 연다.
2. 보드당 처음 한 번 `펌웨어 설치`를 실행한다.
3. 블록을 연결하고 `USB 연결`을 누른다.
4. `보드에 저장·실행`을 누른다.
5. 프로젝트는 브라우저에 자동 저장되며 `.omc3` 파일로 내보낼 수 있다.

## 전송 안정성 및 문제 해결

- 런타임 1.3.0부터 블록 프로그램을 작은 조각으로 나누고, 보드가 각 조각을 확인한 뒤 다음 조각을 전송합니다.
- 이전 1.2.0 펌웨어에도 USB 데이터를 64바이트씩 천천히 보내는 호환 전송을 적용했습니다.
- 현재 수업용 펌웨어는 1.4.8이며 번호별 Bluetooth·Wi‑Fi 이름, `uploadProtocol: chunked-v1`, Bluetooth 시작 대기, 깊게 중첩된 조건·계산 블록, 좌·우 모터 개별 속도, PWM 250 시험 범위와 모터 안전제어를 함께 지원합니다.
- HuskyLens 블록을 작업공간에 넣으면 센서 사용 설정이 자동으로 켜집니다. 얼굴 인식은 100kHz I²C로 안정화하고, 전체 결과에서 학습된 얼굴 ID를 확인하므로 `ID 1 보임?` 블록을 저장형 프로그램에서도 사용할 수 있습니다.
- USB·Bluetooth 연결 시 웹앱이 펌웨어 버전을 확인합니다. Bluetooth 시작 대기 기능을 선택하면 1.4.5 설치를 안내합니다.
- 펌웨어 바이너리 URL에는 버전 식별자를 붙여 브라우저 캐시에 남은 구형 바이너리가 다시 설치되지 않도록 했습니다.
- 번호 저장 후 USB를 다시 연결하면 보드 탭에서 실제 이름(`OneMaker Boat 01~16`)을 확인할 수 있습니다. Bluetooth 선택창에 예전 이름이 남으면 운영체제의 기존 페어링을 제거한 뒤 다시 검색합니다.
- `JSON 명령 오류`가 계속 표시되면 웹앱을 새로고침한 다음 `펌웨어 설치`에서 1.4.0을 다시 설치하고 USB를 재연결합니다.
- 연결 중에는 Arduino IDE의 시리얼 모니터처럼 같은 USB 포트를 사용하는 다른 프로그램을 닫아야 합니다.

## 기술 구조

- Blockly 12 기반 Scratch형 블록 편집기
- Web Serial을 사용한 프로그램·센서 데이터 통신
- Web Bluetooth와 ESP32-C3 Wi‑Fi AP를 사용한 원격조종
- ESP Web Tools를 사용한 초기 펌웨어 설치
- LittleFS에 프로그램을 저장하여 USB를 분리한 뒤에도 실행
- HuskyLens Arduino 라이브러리를 사용한 I²C 비전 센서 블록
- Arduino C++ 코드 자동 생성 및 `.ino` 다운로드

웹앱 경로: `/esp32-c3-boat/`
